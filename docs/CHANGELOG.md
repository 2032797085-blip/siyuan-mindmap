# v0.5.0-dev changes

- Web front-end and editor engine maintained as original source, no minified-JS patch dependencies.
- Webpack alias and local file dependency route all engine imports to `engine/`.
- Rich-text floating-toolbar behavior changed in Vue source, fixed toolbar presentation maintained in `integration/editor/`.
- RAF text redraw implemented in `engine/src/core/render/Render.js`.
- Embedded-mode trial nag suppressed in Vue source.
- Storage exceptions correctly forwarded in Web API source.
- SiYuan custom block, persistence and overlay-mount logic retained from v0.4.6 in `plugin/src/index.js`.
- Offline iframe HTML generated by Vue CLI from maintained `web/public/index.html`, without web analytics.

No rebuilt editor bundle is shipped in the source-only artifact; a clean dependency install and full Vue build are prerequisites for a new binary release.

## Startup title-overlap fix brought forward from plugin v0.4.7
The stable editor-portal component now keeps the iframe invisible until the host layout
is consistent and the embedded editor reports ready. It measures against SiYuan's
`.protyle-title`, guards against collisions, and retains real iframe dimensions
while hidden. It includes `plugin/tests/startup_layout_browser.py`.
This remains a source-only work-in-progress pending a successful full Web build.

## Immediate preview from v0.4.8
- Source plugin now draws a lightweight read-only SVG snapshot synchronously from the saved SiYuan custom-block JSON.
- It defers showing the live iframe until title geometry is safe, preserving the previous collision guard and avoiding the startup waiting message.
- Source-only v0.5.0 remains not build-verified; v0.4.8 patch binary is a separate tested delivery.
