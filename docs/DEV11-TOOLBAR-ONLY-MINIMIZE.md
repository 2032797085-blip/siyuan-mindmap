# v0.5.0-dev.11：独立的功能栏展开 / 最小化

基线：dev.10 的紧凑工具栏；仅修正功能栏按钮控制对象，保留 dev.9 的全部节点与文档兼容逻辑。

- 默认以单行约 46px 的功能栏显示常用操作；其余内容通过文件、更多、格式进入。
- 点击 **最小化功能栏**：仅隐藏功能栏按钮，留下约 30px 高的 **展开功能栏** 入口。思维导图白板、画布尺寸和编辑会话均不改变。
- 点击 **展开功能栏**：恢复紧凑工具栏；不调用思源外层导图块的“最小化/展开/放大”。
- 富文本工具始终保持组件挂载，收起时关闭浮出面板，展开后可再次点击格式。
- 导图块标题栏原有“最小化/展开”控制仍然保留，用于收起整张导图；与此功能互不干扰。
- standalone Web 编辑器的功能栏仍保持原状；仅 `window.takeOverApp` 的思源嵌入模式生效。

修改：`web/src/pages/Edit/components/Toolbar.vue`，版本信息、回归测试与说明。没有修改 `engine`、快捷键、保存数据格式及 PowerShell 部署脚本。旧版桥接的整图工具动作接口仍存在但新功能栏不调用。

构建：在现有工程中按原路径覆盖补丁，退出思源后执行 `build-and-deploy.ps1`。建议在正式安装前备份已有源码和插件。

测试范围：Node 源码回归测试、Chromium 功能栏尺寸与点击切换。没有完成用户的真实 SiYuan 桌面客户端验证；编译能否成功需要用户本机运行确认。
