# v0.5.0-dev.4：最小化显示中心主题

本版以 v0.5.0-dev.3 为基线，仅调整思源插件外层的折叠标题栏。

## 效果

- 正常展开时标题仍为「思维导图」。
- 点击「最小化」时，标题栏显示当前导图根节点（中心主题）的文字。
- 编辑完中心主题后立即最小化，会沿用 v0.5.0-dev.3 已有的编辑完成、同步数据、保存成功后才折叠的流程，标题使用最新同步的数据。
- 中心主题为空时显示「未命名思维导图」。富文本格式标签不会显示成 HTML，`textContent` 确保不会执行 HTML/脚本。
- 内容太长时单行省略；鼠标悬停显示完整主题。
- 同文档多个导图分别独立显示标题；标题不会写入思维导图数据，重新展开还是原来的 iframe。
- 不记忆折叠状态；重新打开文档仍默认展开（与 dev.3 一样）。

## 变更文件

- `plugin/src/index.js`：增加纯读 `centerTopicTitle()`，仅在折叠时展示，已有 `applyPatch` 收到中心主题变动后刷新。
- `plugin/index.css`：折叠标题的省略样式。
- `plugin/tests/logic.test.cjs`：新增中心主题、富文本、安全、最新提交、多个块、展开恢复测试。
- `package.json` 与 `plugin/plugin.json`：同时更新版本号为 `0.5.0-dev.4`。

**不修改 `engine/`、`web/`、`integration/editor/bridge.js` 或 PowerShell 部署脚本。**

## 安装

将源码补丁 ZIP 中的文件按相同目录结构覆盖到 `D:\思源笔记插件制作程序\siyuan-思维导图`，不要解压到思源的 `data\plugins`。先备份现有源码和工作空间，完全退出思源，然后在 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\思源笔记插件制作程序\siyuan-思维导图\build-and-deploy.ps1"
```

编译应显示 `0.5.0-dev.4`，最后需要看到 `DEPLOY SUCCESS.` 才算部署完成。

## 建议实测

1. 将中心主题改为“数学知识体系”，马上点击最小化，确认折叠标题显示新名称。
2. 展开，修改中心主题，再次折叠，检查标题更新和原有节点未丢失。
3. 中文输入法文字确认、很长标题、空标题、不同导图块分别折叠。
4. 保存后重新打开思源文档，检查节点数据不变。
5. 展开后检查 F2、删除键、方向键、Enter、Tab、撤销、重做。

本补丁可以做源码级测试和浏览器布局验证，但用户本机的 SiYuan 客户端仍需要实测。
