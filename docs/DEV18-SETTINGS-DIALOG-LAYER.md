# v0.5.0-dev.18 — 修复原生设置窗口被遮挡

基于 dev.17。仅修改 `plugin/index.css` 的浮层层级：

- 不再强制提高思源文档的 `.protyle-breadcrumb` 和 `.protyle-util` 层级；这些元素会盖住思源设置窗口的上方。
- 未打开原生对话框时，继续保证思源原生 `.protyle-hint`、`.protyle-toolbar` 和 `.b3-menu` 可覆盖导图 iframe。
- 打开任何 `.b3-dialog--open` 原生对话框时，取消额外的弹出菜单层级，且放大状态的导图不会覆盖对话框。
- 不销毁 iframe、不隐藏整个导图、不改变保存逻辑或键盘处理。

风险低，需在 Windows 思源客户端实测：创建导图后打开 设置 → 编辑器，应能看到完整设置窗口顶部、关闭按钮且可点击；关闭后再检查 `/` 菜单、选区菜单、放大导图和节点编辑。
