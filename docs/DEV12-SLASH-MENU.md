# v0.5.0-dev.12 — 思源 / 菜单插入思维导图块

本次仅添加 `this.protyleSlash` 注册，不监听原生 `/` 按键、不更改菜单 DOM、不修改原来的工具栏或面包屑入口。

- 在可编辑的思源正文中输入 `/`，搜索“思维导图块”（也支持“导图块”、`swdtk`）。
- 选择标注“插件”的“思维导图块”，插入一个中心主题为“中心主题”的自定义块。
- 与思源内置的“思维导图”（列表型思维导图）不同。
- 插入过程使用 SiYuan 提供的 `protyleSlash.callback` 与 `protyle.insert`，复用原来的 `mindMapMarkdown` 数据格式。
- 仅供可编辑文档使用；测试于正常段落。已有块的编辑、保存、快捷键和 PowerShell 脚本未修改。

## 手工验收

1. 在文档新段落输入 `/思维导图块` 并选择菜单项，确认只插入一张图。
2. 在不同文档重复，确认两张图互不影响且能保存和重新打开。
3. 不输入 `/`，分别通过原工具栏和面包屑插入，确认仍能创建。
4. 选择内置“思维导图”，确认它仍是思源自带的列表视图，不应受插件影响。
5. 检查输入普通 `/` 命令、F2、Delete、Backspace、方向键及最小化功能正常。
6. 只读模式中应无法创建插件导图块。

当前只做了 Node 回归测试，未经用户本机 SiYuan / Vue 全量构建验证；部署前备份原插件和工作空间。
