# v0.5.0-dev.14 — 可延伸总结节点（试验功能）

本版基于 **v0.5.0-dev.13**，针对用户确认的安全替代方案，仅在思源内嵌编辑器添加一个普通“总结”节点的创建快捷键，不修改 SimpleMindMap 的原生概要（Generalization）数据结构。

## 操作

1. 在思维导图画布中**单选一个普通节点**（中心主题或分支节点都可以）。
2. 按下 **Alt + ]**（键盘的右方括号键，中文界面也可记为 Alt + 】）。
3. 引擎在这个节点的下一级创建一个名为 **“总结”** 的普通子节点；新节点默认选中，但不会强行打开富文本编辑框。
4. 继续按 **Tab** 为“总结”添加下一层节点，或按 **F2** 编辑总结文本。其他节点操作保持引擎原有行为。

原生概要仍然通过 **Ctrl + G** 创建，并保留其括号式外观；**Alt + ] 不再创建原生概要**。原生概要仍不能添加子节点。

注意：本功能**不是**让多个分支在布局上汇合到一个有子节点的原生概要。若需要真正的“多分支汇总并继续延伸”，将涉及引擎的数据模型与布局重构，不属于本次补丁。

## 风险和保护

- **不修改 `engine/` 下任何文件**；使用原有 `INSERT_CHILD_NODE(false, [node], { text: '总结' })` 命令，沿用引擎默认布局、历史记录和文档保存机制。
- 仅在 SiYuan 内嵌模式（`window.takeOverApp`）注册；只在**恰好选中一个普通节点**时创建，多选或选中原生概要时不创建，防止误操作。
- 普通 Web 编辑器、Ctrl+G 原生概要、F2、Backspace、Delete、Enter、Tab、方向键、保存格式、PowerShell 部署脚本未修改。
- 在输入框或中文输入法文本编辑状态中，依赖已有 `KeyCommand` 及编辑器的快捷键暂存机制，不额外注册全局 DOM 键盘监听器。
- 当前只经过 59 项本地 Node 源码/行为测试及版本检查；未在用户 Windows 10 + SiYuan 环境执行完整 Webpack 编译和实机快捷键/输入法测试。

## 安装和回滚

先备份源码和 SiYuan 工作空间；将 **dev.14 增量补丁 ZIP** 按原目录结构覆盖到 `D:\思源笔记插件制作程序\siyuan-思维导图`（应已是 dev.13），然后关闭思源，通过既有 `build-and-deploy.ps1` 一键部署。查看日志中 `0.5.0-dev.14` 与 `DEPLOY SUCCESS.`。脚本会在替换原插件前创建备份。

测试时先使用新建的临时导图，依次检查 Alt+] 插入总结、Tab 添加后续节点、保存并重新打开、Ctrl+Z 撤销、Ctrl+G 原生概要与 F2/删除键。若有异常，停止正式使用，从部署备份恢复原插件，并把源码恢复到 dev.13 完整包。
