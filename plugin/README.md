# 思源思维导图 v0.3.0（文档内嵌测试版）

基于 SimpleMindMap 和思源笔记的官方插件 API 构建。导图以 `;;;siyuan-mindmap/mindmap` 自定义块存储在思源文档中，可以在正文内编辑。

## 本版修复：保存后编辑器重载 / 闪白屏

v0.2.0 的 `setContent()` 会写入文档块，在某些思源版本中这会触发自定义块重新渲染，造成编辑器 iframe 不断销毁/加载。

v0.3.0 将 iframe 固定挂载到文档页面外部，通过跟随正文占位块的位置显示。自定义块即使保存后重新渲染，插件也会识别同一块和同一编辑器实例，复用原 iframe，避免打断正在编辑的画布。数据仍然通过官方 `setContent()` 写入当前文档块，而非仅仅存到浏览器缓存。

## 安装 / 更新

1. **先备份工作空间**。建议先在测试文档中试用。
2. 完全退出思源。将旧 `data/plugins/siyuan-mindmap` 文件夹备份到 `data/plugins` 之外的位置。
3. 将本安装 ZIP **里面全部文件和文件夹**解压到 `工作空间/data/plugins/siyuan-mindmap/`，注意 `plugin.json` 应直接位于该文件夹内。
4. 启动思源，在 `设置 -> 集市 -> 已下载` 启用 `思源思维导图`。
5. 打开文档，在编辑工具栏或面包屑工具栏点击思维导图按钮插入。

已在 v0.2.0 文档中插入的自定义导图块，不需要重新创建，原始数据格式保持兼容。

## 支持的功能

- 文档内嵌 SimpleMindMap 编辑器，多导图块，各自保存到对应的块内容
- 画布拖动、编辑节点、布局、主题、导出等能力由原 SimpleMindMap 提供
- 自动保存：编辑停止 1.3 秒后尝试持久化到文档；也可点「保存」
- 编辑区高度调整、放大编辑
- 卷动文档时跟随导图占位块调整位置，切换文档后释放画布

## 测试与限制

**这是修复测试版，并未在真实思源桌面客户端做端到端测试。** 包括多窗格并排、思源缩放、不同主题、复杂滚动/全屏、撤销和重做在内的场景都需要实际使用验证。

编辑器使用独立的浮层来避免自定义块重建时重复初始化，可能在特殊布局/弹出菜单/滚动等场景存在显示偏移。如果出现显示异常，请发送截图和开发者工具控制台报错，便于继续修复。

若 1.3 秒内强制终止思源进程，最后的修改可能尚未持久化。重要内容请点击「保存」，并确认右上角出现「已保存到文档」。

## 数据存储与安全

数据存储在思源自定义块的原始内容中。并未使用外部网络接口同步数据。建议试用期间定期备份工作空间。

## v0.4.0 默认主题

首次安装后，新插入的导图默认采用「简约黑」主题。
在思源「设置 → 集市 → 已下载」中找到「思源思维导图」，打开插件设置，选择「新建导图的默认主题」，确认保存。
设置仅用于之后插入的导图。文档中已有的思维导图不会被更改；已有导图可以使用编辑器右侧「主题」面板单独换主题。

## v0.4.2 输入性能优化

将 SimpleMindMap 文本编辑时的节点尺寸重绘防抖从 100ms 调整为 32ms，使连续输入时节点边框更快跟随文字。保存间隔及文档数据格式保持不变。连续输入长文本或大型导图可能增加 CPU 占用；实际体验仍需在思源客户端检验。


## v0.4.3 修复：提示及保存异常

- 修正 v0.4.2 打包回退：继续移除不适合思源内嵌场景的“网页版仅供试用”启动提示。
- 修复 SimpleMindMap Web 构建将任何保存异常误报为浏览器存储额度不足的问题。
- 思源接管保存时，真实异常会显示“数据传送失败，当前更改可能未保存”，并在开发者控制台记录原因，不会无故堆叠额度超限通知。
- 真正的非接管模式浏览器 QuotaExceededError 仍保留警告。
- 保留 v0.4.2 的文字节点重绘 32ms 防抖优化、默认“简约黑”及历史导图数据格式。

**使用前请备份思源工作空间；实际保存可靠性需要在真实思源客户端验证。**


## v0.4.4 输入与节点尺寸逐帧同步

- 将 v0.4.2 的 32ms **尾随防抖** 改为 `requestAnimationFrame` **逐帧合并更新**：首次修改排到下一次屏幕绘制帧，不需等待用户停止输入；在同一帧发生的多次修改只使用最后一份文本。
- 普通屏幕 60Hz 一帧约 16.7ms；具体画面响应还受到布局、节点数量及屏幕刷新率影响，无法承诺绝对零延迟。
- 未改动数据格式、自动保存策略、原有主题设置、之前的试用提示和浏览器存储错误修复。
- 若大型导图重绘占用明显，可在后续版本增加性能档位；建议备份并先在测试文档中验证中文输入法和长文本。


## v0.4.5 将富文本工具移至顶部工具区

- 新增「文字格式」固定工具行，位于顶部节点工具区内，复用上游原有的加粗、斜体、下划线、删除线、字体、字号、文字色、背景色、对齐、清除格式等命令。
- 选中文字仅激活顶部工具栏，**不再在选区附近创建或定位悬浮条**；未选中文字时工具栏灰显，不干扰普通画布操作。
- 原有下拉颜色/字体选择仍按用户点击（或鼠标悬停）打开；保留默认主题、保存及之前的性能优化。
- 新增 editor/format-toolbar.js 与 editor/format-toolbar.css，编译版 Vue 富文本组件只做 3 个有针对性的调用/状态补丁。
- 仍须在真实思源客户端核对中文输入法、字体格式操作、长文本及工具栏响应式布局。

- 布局模拟（无完整思源宿主）验证格式工具确实位于顶部主工具区域内、且在未选区时不可点；由于沙盒环境禁止打开本地/localhost URL，未能运行完整的编辑器浏览器端到端测试。


## v0.4.6 — 修复与思源界面的遮挡

- 导图 iframe 现在持续驻留在它所属的 `.protyle` 编辑器容器下（而不是 `document.body` 的高层浮窗），层级由 `8` 降为 `1`。原始 iframe 不因保存时重渲染而销毁。
- 提升思源斜杠菜单、文本悬浮工具栏在对应编辑器中的显示优先级，不再让导图盖住文档菜单。
- 为标题高度和内容位置变化增加输入、MutationObserver 和 ResizeObserver 定位通知，导图跟随正文的真实位置移动。
- 保留 v0.4.5 的固定文字格式工具栏、默认主题、流畅输入和自动保存。
- **尚未在真实思源桌面客户端测试**。请备份工作空间后在测试文档里验证：编辑标题、输入 `/` 菜单、选择文字、滚动、保存、切换标签页。
